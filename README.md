# 마법의 소라고둥

한국어 정적 Vite 앱. 서버 없이 JSON/SQLite·IndexedDB 선택지에서 답을 고릅니다. 선택적 모델 다운로드 후 질문과 후보는 브라우저 안에서 계산합니다.

```
npm ci
npm test
npm run build
npm run prepare:laya-assets
```

`/magic_conch/`에 배포합니다. 마지막 명령은 검증된 Laya 모델 Release를 받아 `dist/models/laya/`에 복사합니다. 개발 테스트는 가중치 없이도 가능하며 Laya 로드는 자산 준비 후 동작합니다.

- 원작 짧은 한국어 답100개 + 안내9개, 자연질문88개/의도22개. 책 전문이 아닌 앱용 새 문장입니다.
- 기본 키워드와 기존 E5 q8 개인 DB 검색 유지. JSON/SQLite20MB·2,000행 제한, 384차원 E5 임베딩 계약 유지.
- 한국어 SRoBERTa q8 문장 검색: no prefix, mean+normalize,768차원. 제공 예시의 자연질문을 검색하며 새 벡터는 기존 E5 DB embedding 필드와 섞지 않습니다.
- 실제 Laya Multilingual trained encoder/head 선택적 실험 모드. 명시적인 약681MB 다운로드·진행 상태·캐시·실패·재시도. FP16 저장/FP32 계산은 모든 압축 가중치의 원본 복원을 검증했습니다.
- 개인 가져오기 내용은 자동 교체하지 않습니다. 새 예시를 쓰려면 '기본값 복원'의 확인을 직접 선택하세요.
- 질문을 저장하지 않습니다. 선택지/기존 E5 벡터는 IndexedDB에 저장하고 다운로드 모델은 브라우저 CacheStorage를 사용합니다. SQLite는 sql.js WASM이며 임베딩은 little-endian Float32 BLOB입니다.

[품질 실험과 한계](docs/quality-report.md), [데이터 형식](public/schema-guide.txt), [모델·콘텐츠 조사](research/README.md). Laya는 평가상 한국어 검색보다 더 좋다고 확인되지 않아 기본값으로 강제하지 않습니다. 점수와 출력은 개인의 중요한 결정이나 사실의 정답을 보장하지 않습니다.

후속 회귀 수정: 가까운 보호 의도가 경쟁하면 질문 확인으로 보류하며 Laya도 안내 후보로 제한합니다. 별도 최신정보 안내를 포함해 기본 DB109개입니다. 일반답100개 중 한국어 첫답12개, Laya 후보43개에 현재 연결됩니다. 최종 authored16문항 CPU smoke 결과와 한계는 `docs/quality-report.md`에 있으며, production 새버전 브라우저 검증은 아직 미실행입니다.

동결 b622의 새68문항 평가에서 사진 공개 거절 문맥의 부적절한 행동 권유와 필요한 안전 안내 누락을 확인했습니다. 현재 실험 모델의 답변 적합성을 보장하지 않습니다. raw 결과/예비 검토는 `research/independent-final/`에 있으며, 모델 이름을 가린 한국어 사용자 내용 검토는 아직 필요합니다. 후속 오류 복구 수정은 모델 실패를 명시적 보류로 끝내며 정상 검색 의미 정책을 바꾸지 않았습니다.

개발 후보 v2는 `research/context-routing-v2` 브랜치에서 검토 중이며 라이브 배포는 보류합니다. 문맥/검색 보호 경로와 실제 Laya 선택을 분리하고, 기본 DB는123개·질문 예시는176개입니다. 한국어 의미 검색은 명시적으로 모델을 켠 경우 적용되며, 다운로드 없는 가벼운 경로와 성적을 구분합니다. 방법·ablation·개발 스트레스·한계는 `research/pipeline-v2/REPORT.md`에 있습니다. 기존68문항은 이제 회귀 자료입니다. 새 독립 최종검증 전에는 개발셋 적합을 일반 품질로 해석하지 않습니다.


## Scoped permission evidence review

공개 허락이 불분명한 요청에는 게시 대상·공개 범위의 명시 동의를 확인하는 안내를 유지합니다. 한 절의 부정으로 보호 경로 전체를 삭제하지 않습니다. 기본 샘플은124개이고 사용자 DB는 자동 교체하지 않습니다. 모델 오류·시간 초과 시 안내를 유지하는 기존 처리도 보존합니다. 별도 검토 브랜치이며 배포는 보류합니다.
