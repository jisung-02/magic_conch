# 마법의 소라 한국어 콘텐츠

## 구성과 출처
- `answers.ko.json`: 새로 작성한 일반 답변 100개(10개 범주 × 10개), 별도의 안전/명확화 응답 8개, 출처와 작성 경위.
- `question-cases.ko.json`: 긍정문·부정문·유사 표현 15세트(45개 문장), 기대 의미와 라우팅 예시. 홀드아웃 검증 후보.
- `retrieval-intents.ko.json`: 22개 의도/위험 질문군과 자연어 예시 88개, 응답 경로 및 답변 ID 연결. 검색 코퍼스로 사용하고 홀드아웃 예시와 분리한다.
- 특정 책의 본문 데이터, 번역본, 문장 목록이 아니다. 사용자가 지칭한 책의 신원도 아직 확정되지 않았다.
- 확인된 도서 후보: 캐롤 볼트 『내 인생의 해답』, 천수현 옮김, 쇼비, 2010-12-24, ISBN 9788996550105. [알라딘 서지](https://www.aladin.co.kr/shop/wproduct.aspx?ItemId=11397333)
- 별도 문구 상품 후보: ‘결정의신 - 마법의 고민 해결책’. [YES24 상품](https://www.yes24.com/product/goods/94869514)은 문구/GIFT로 분류하며 제조자/수입자를 한달살이(먼스플라이)로 표시한다. 갓샵은 판매 표기이며 저자/출판사로 단정하지 않는다.
- 핑크풋 고민해결책 계열도 검색에서 확인되지만, 특정 판본과 본문은 확인하지 않았다.
- 원출판사에서 확인한 공통 구조는 질문을 생각하고 책을 펼쳐 짧은 답을 얻는 형식이다. [Penguin 출판사 소개](https://www.penguin.co.uk/books/330036/the-book-of-answers-by-bolt-carol/9780553813548), [Hachette 시리즈 소개](https://www.hachettebookgroup.com/series/carol-bolt/book-of-answers/). 영문 소개의 쪽수나 문장 수를 한국어 판본에 그대로 적용하면 안 된다.

## 데이터 필드
- `id`: 안정적인 식별자. 화면 문구를 바꿔도 기존 ID를 보존할 수 있다.
- `category`: 답의 기능. `go`, `pass`, `wait`, `rethink`, `check`, `ask`, `small`, `priority`, `uncertain`, `play`.
- `text`: 사용자에게 보이는 한국어 답. 원문 인용을 뜻하지 않는다.
- `semanticAction`: 질문의 표면적인 예/아니오가 아니라 답이 권하는 행동.
- `allowedRisk`: 현재 일반 답변은 모두 `low` 전용.
- `tone`: `plain` 또는 `playful`.
- `original`: 이번 앱용으로 새로 작성했음을 표시. 기존 문학과 겹침이 없다는 법적 보증은 아님.
- `routingResponses`: 일반 랜덤 풀에 섞지 않는 고위험/명확화 응답. 이 콘텐츠만으로 완전한 안전 분류기가 되지 않음.

## 의미를 유지하는 선택 규칙
1. 문장 전체와 대화 맥락으로 사용자가 궁금해하는 행동/사실을 확인한다. 단일 키워드가 아니라 부정 범위, 선택지, 시점, 대상, 위험도를 함께 본다.
2. 고위험·동의·자해 우려를 먼저 처리한다. 그 경우 일반 답변 100개를 무작위 선택하지 않는다. 지역 응급 정보는 검증된 별도 출처가 있을 때만 제공한다.
3. ‘비가 올까’, ‘상대가 나를 좋아할까’처럼 사실/타인의 속마음을 묻는 질문에는 행동 명령이나 예언을 대입하지 않는다. 알 수 없음을 인정하고 확인 가능한 경로를 제시한다.
4. 낮은 위험도의 취향/작은 선택에서만 어울리는 범주를 고른다. `play`도 상황이 맞을 때만 사용한다. 간식/달력/창밖 문장은 모든 질문에 맞는 만능 답이 아니다.
5. ‘연락할까?’와 ‘연락하지 말까?’에 같은 ‘응’을 출력하지 않는다. 두 문장을 ‘연락을 한다’라는 명제로 정규화한 뒤, ‘짧게 안부부터 전해 봐’처럼 행동이 드러나는 답을 쓴다.
6. 같은 사안의 단순 말바꾸기에는 같은 의미의 답을 유지한다. 개인정보가 섞인 질문 원문을 무조건 저장할 필요는 없다. 세션 내 명제 식별과 응답 의미를 유지하면 된다. 새 조건이 제시되면 재판단한다.
7. 문맥을 이해하지 못했다면 ‘질문의 뜻을 조금만 더 알려 줘’로 명확화한다. ‘다시 물어봐’만 반복하는 흐름은 피한다.

## 사용자에게 보여 줄 설명 예시
“가벼운 고민에 한마디를 건네는 소라예요. 답변은 새로 쓴 한국어 문장들이며, 실제 책의 문장을 수록한 것은 아니에요. 중요한 결정은 충분한 정보와 함께 해 주세요.”

## 검증
JSON 구문, ID/텍스트 중복, 일반 답변 수, 범주 수를 검증했다. 문장별 적합성과 안전한 라우팅은 실제 구현에서 별도 검증해야 한다. 이 문서는 구현 완료를 주장하지 않는다.

## 검색 매핑 필드
- `questionExamples`: 임베딩할 실제 한국어 질문 예시. 키워드 묶음이 아니다.
- `risk` / `route`: 답변 선택에 앞서 확인할 위험도와 응답 경로.
- `eligibleAnswerIds`: 콘텐츠 풀에서 검토 가능한 문구 ID. 모두가 현재 질문에 맞는다는 보증도, 객관적 정답도 아니다. 문장 의미와 맥락을 반영하는 선택 단계가 필요하다.
- `routingResponseId`: 안전/명확화 경로에서 참조하는 별도 응답 ID.
- `selectionContract`: 점수 해석, 부정문 처리, 세션 일관성과 외부 정보 경로의 계약.

추가 임베딩 연구/벤치마크 파일은 별도 담당 작성물이며 이 문서의 100문장 검증 범위와 구분된다.
